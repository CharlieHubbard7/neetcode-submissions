# NeetCode and LeetCode solutions

My accepted solutions to interview-style problems, in Python. So far: 24 NeetCode problems and 4 LeetCode problems.

- `Data Structures & Algorithms/`: NeetCode solutions, one folder per problem. Each attempt is saved as its own `submission-N.py`, so earlier tries are kept.
- `LeetCode/`: one folder per problem, holding the problem statement and the solution.

New solutions are committed automatically: NeetCode through its GitHub sync, and LeetCode through the [LeetSync](https://github.com/LeetSync/LeetSync) extension.
